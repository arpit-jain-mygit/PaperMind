#### [3512. Minimum Operations to Make Array Sum Divisible by K](https://leetcode.com/problems/minimum-operations-to-make-array-sum-divisible-by-k/)
**Easy** | Acceptance: 92.3%

You are given an array of integers `nums` and an integer `k`. In one operation, you can pick any index `i` in the array and increment `nums[i]` by `1`.

Return the minimum number of operations needed so that the sum of the array is divisible by `k`.

**Example 1:**
```
Input: nums = [3,9,5], k = 2
Output: 3
Explanation: We can perform operations to make the array [4,9,6]
4 + 9 + 6 = 19, which has remainder 1 when divided by 2.
Actually, we need [4,9,6] which sums to 19. Let me recalculate.
```

**Approach:**
1. Calculate current sum % k
2. Find how many increments needed to make sum divisible by k
3. Use math: if remainder is r, we need (k - r) operations

### 90% - 85% Acceptance

#### [263. Ugly Number](https://leetcode.com/problems/ugly-number/)
**Easy** | Acceptance: 43.9%

An ugly number is a positive integer which does not have a prime factor other than 2, 3, and 5.

Given an integer `n`, return `true` if `n` is an ugly number.

**Example 1:**
```
Input: n = 6
Output: true
Explanation: 6 = 2 × 3
```

**Example 2:**
```
Input: n = 1
Output: true
Explanation: 1 has no prime factors.
```

**Example 3:**
```
Input: n = 14
Output: false
Explanation: 14 is not ugly since it includes the prime factor 7.
```

**Constraints:**
- `-2^31 <= n <= 2^31 - 1`

**Approach:**
```python
def isUgly(n):
    if n <= 0:
        return False
    
    # Divide by 2, 3, 5 as many times as possible
    for prime in [2, 3, 5]:
        while n % prime == 0:
            n //= prime
    
    # If n is 1, it's ugly (only had factors 2, 3, 5)
    return n == 1
```

**Time Complexity:** O(log n)
**Space Complexity:** O(1)
